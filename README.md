# Himalayan FruitCha 🏔🍎

**Born in the Mountains. Inspired by Fruit.**

Himalayan FruitCha is an apple-based fruit-tea venture inspired by the
apple-growing heritage of Jammu & Kashmir. This repository contains the
brand's e-commerce website, built as a single `index.html` file.

📍 Village Kalsian, Nowshera, District Rajouri, Jammu & Kashmir, India
👤 Founder & CEO: Harsh Rachyal

## Products
- Golden Apple Fruit Tea
- Green Apple Fruit Tea
- Red Apple Fruit Tea

20 tea bags per box (subject to final packaging confirmation).

## Features
- Responsive, mountain-inspired premium design
- Product catalogue with quantity selector and shopping cart (saved in local storage)
- Dispatch-goal progress bar (orders dispatched once collective order requests reach ₹10,000)
- Integrated checkout: customer details, delivery address, order summary, payment method, confirmation
- Payment options: PhonePe / UPI (QR + UPI ID + copy button), Cash on Delivery, Net Banking
- Order requests sent to WhatsApp with a formatted order summary
- Payment is never marked as paid automatically; it is verified manually
- Return, replacement and refund policy; FAQ; founder and mission sections
- Admin panel to edit prices, descriptions, availability, images and settings

## Run locally
Download the files and open `index.html` in a browser. No installation needed.

## Deploy
Drag the project folder onto [Netlify Drop](https://app.netlify.com/drop)
or enable GitHub Pages in the repository settings.
